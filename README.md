# OIBSIP_Python_Task4
Developed a real-time Python chat application with GUI, user authentication, multiple chat rooms, message history, emoji support, notifications, and SQLite database storage.

**Objective:**  
To develop a real-time chat application that enables users to communicate through multiple chat rooms with authentication and message history.

**Steps Performed:**  
1. Created a client-server architecture using Python sockets.  
2. Implemented user registration and login authentication.  
3. Developed a Tkinter-based graphical chat interface.  
4. Added multiple chat rooms and room creation features.  
5. Implemented real-time messaging using threading.  
6. Stored users, rooms, and messages using SQLite.  
7. Added message history, emoji support, and notifications.  
8. Tested communication between multiple users.

**Tools Used:**  
Python, Tkinter, Socket, Threading, SQLite3, JSON, and Hashlib.

**Outcome:**  
Successfully developed a functional real-time chat application supporting authentication, multiple rooms, message history, emoji conversion, notifications, and database storage.
